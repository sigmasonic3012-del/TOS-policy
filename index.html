02What TradeGuard Does

TradeGuard provides trading-community utilities inside Discord, including:

  • Real-time price alerts and watchlists for supported markets

Privacy Policy

01Information We Collect

To operate trading-community features, TradeGuard collects:

  • Discord identifiers — user ID, server ID, channel ID, role ID
  • Command inputs — ticker symbols, alert thresholds, watchlist entries you type into TradeGuard commands
  • Manually entered portfolio data — trade entries you choose to log; TradeGuard never connects to exchange accounts or wallets automatically
  • Moderation signals — flagged links, reported messages, and account-age metadata used for scam detection
TradeGuard never requests, stores, or has access to wallet private keys, seed phrases, exchange API secrets, or account passwords. There is no feature that could collect this data.

02How We Use Information

Collected data is used to: run price alerts and watchlists you configure; display your logged portfolio back to you; power the scam-detection and verified-badge systems; and diagnose bugs through error logging.

03Data Storage & Security

Data is stored on encrypted infrastructure hosted with DigitalOcean, using a MongoDB database with access restricted to authorized Nova Labs LLC personnel. We apply reasonable technical safeguards, but no system is 100% secure.

04Data Retention

Server-specific configuration and alert data is retained while TradeGuard remains in your server, and deleted within 30 days of removal. Moderation logs used for scam-pattern detection may be retained up to 90 days for investigation purposes.

05Data Sharing

We do not sell user data. Limited data may be shared with: infrastructure providers strictly necessary to run the bot; law enforcement, if legally compelled; or other Discord server moderators, limited to scam-report evidence you submit.

06Your Rights

You may request access to, correction of, or deletion of your data by contacting us below. Removing TradeGuard from a server or deleting your logged portfolio entries via /portfolio clear also removes associated data.

07Children's Privacy

TradeGuard is not directed at users under 13, consistent with Discord's own minimum age policy. We do not knowingly collect data from users below this age.

08Changes to This Policy

We may update this Privacy Policy periodically. Material changes will be reflected in the effective date above.
